    🖥 macOS

    Название: Happ
    Российский App Store: https://apps.apple.com/ru/app/happ-proxy-utility/id6783623643
    Файл DMG: https://github.com/Happ-proxy/happ-desktop/releases/latest/download/Happ.macOS.universal.dmg

    Добавление подписки

    1. Установите приложение Happ
    2. В боте нажмите "📱 Мои устройства" → "📲 Подключить устройство" → "🖥 Mac" и скопируйте ссылку из сообщения: правый клик по ссылке → «Копировать»
    3. В Happ нажмите "+"
    4. "Вставить из буфера"
    5. Разрешите добавить конфигурацию (macOS спросит один раз)
    6. Нажмите кнопку подключения
